Implement the work described by the user in the spec or tickets.

Before changing code, discover the project's applicable implementation, testing, verification, documentation, and versioning instructions. Write or update the required tests before implementing the behavior, then run the project's required focused and full verification commands.

After implementation, use the project's supported review workflow. Do not commit unless the user explicitly asks.
