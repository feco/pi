---
name: research
description: Research a question against high-trust sources and return a concise cited brief. Use when the user wants a topic investigated, documentation or API facts gathered, or external reading legwork delegated.
---

1. Bound the question to 2–4 research angles. Stop when each material angle has direct evidence or is reported as an unresolved gap.
2. Prefer primary sources: official documentation, source code, specifications, first-party APIs, and peer-reviewed research. Use secondary sources only to find or independently compare primary evidence. Trace consequential claims to the source that owns them.
3. Return a concise inline brief: a 2–3 sentence summary, numbered findings with direct source links, notable source-quality decisions, and remaining gaps. Distinguish evidence from inference.
4. Write a durable Markdown artifact only when the user requests one or later work needs it. Follow the repository's existing convention; if none exists, ask before introducing one.
