# Grilling with a project gap

Run a `/grilling` session. Before the first round, discover the project documentation instructions and the applicable gap-artifact convention. Create or open the initiative's gap artifact before recording decisions.

After every round, update the gap artifact with the durable outcome: the problem, intended end state, settled decisions, open questions, dependencies, rejected options, and scope boundaries. Keep the artifact concise: do not copy the conversation verbatim or add facts the user did not establish.

Use the project's established terminology and document locations. Follow its frontmatter, navigation, linking, and validation requirements. If the project requires a separate durable decision record, link it from the gap artifact while retaining the decision's execution impact in the gap.

At the end of the session, ensure the gap's remaining open items match the unresolved frontier and tell the user where the artifact was updated.
